# Redmi9T-Native-Linux

Компактная передача основных наработок Claude Code. Начать с [CLAUDE.md](CLAUDE.md) и [handoff/START_HERE.md](handoff/START_HERE.md).

Linux v8b, аппаратный FD610 и GNOME50 на физическом LCD уже работают. Текущий приоритет — Novatek NT36672A; реальных касаний ещё не получено. Последний live preflight остановлен до SPI.

Включены исходники, конфигурации, build scripts, основные отчёты, последние логи и r2-модули. Большие boot/rootfs, backups, SDK и старые дубли оставлены на ПК; пути и SHA256 — в handoff/LOCAL_LARGE_ARTIFACTS.json.

Не запускать hardware/flash/reboot scripts автоматически. [Последний результат](TOUCHSCREEN_FIRST_LIVE_RESULTS.md).
