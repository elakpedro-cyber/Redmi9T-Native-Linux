# Задание специалисту — обесточенная плата Redmi 9T NFC

Цель — идентифицировать конкретную плату и модуль, установить проверенные точки измерения и возврата. По сервисной процедуре отключить батарею, USB и другие источники, использовать ESD-защиту и проверить остаточное напряжение до прозвонки. Не подавать внешнее питание или тестовые сигналы на цепи. Использовать только подтверждённые точки и допустимый для цепи метод прозвонки. Если направление или состав цепи расходятся с документацией, зафиксировать расхождение и остановить проверку этой цепи.

| Пункт | Источник и уверенность | Что вернуть после осмотра |
|---|---|---|
| Ревизия PCB/assembly | Высокая для DT идентификаторов SoC 444 rev 1.0 и платформы 0x22 / 0x10000 / 0, неизвестная для ревизии PCB и BOM. | CN2701 и модуль | Высокая для выбора профиля TD4330 Truly v2 в архивных данных. Средняя для CN2701 по копии схемы J19S, лист 27. | PM6125 S5 / L9 / L18 | Высокая для программной роли S5 как MX, L9 как VDDIO и L18 как VDDA Host. Средняя для разводки данного экземпляра. Сверить VDDIO на стороне CN2701. |
| REFGEN | Высокая для запроса DSI Host, неизвестная для электрического provider. [Анализ](VDDMX_REFGEN_EVIDENCE.md) | Если документация данной ревизии явно показывает внешний reference, вернуть ссылку и фото. `PMI_REF_BYP` не считать его подтверждением. Отсутствие внешнего компонента не определяет внутреннюю реализацию. |
| Подсветка и enable | Средняя для U2732 и GPIO99 HWEN, LED_A и I²C 0x36. LM36923YFFR — вариант из схемы. Ответ на том же I²C адресе не отличает варианты BOM. [Схема, л. 8, 27](https://www.scribd.com/document/613010966/Xiaomi-Redmi-9T-Schematic-pcb) · [Карта](../REDMI9T_DISPLAY_HARDWARE_MAP.md) | Маркировка U2732, цепи HWEN/LED_A и их доступные точки. |
| LCD reset и PMI_DISP_HW_EN | Средняя для назначения по исходникам и схеме, неизвестная для физического поведения и полного lifecycle. [Карта](../REDMI9T_DISPLAY_HARDWARE_MAP.md) | Подтверждённые reset/enable nets, топология и доступные точки наблюдения. Не смешивать LCD reset, GPIO99 HWEN и reset сенсора. |

Передать аннотированные макрофото без IMEI/серийных номеров, фрагменты проверенной схемы, таблицу «цепь / точка / метод / результат / уверенность / источник», обозначение опорной точки и чертёж подходящего interposer при необходимости. Неподтверждённое записать как UNKNOWN. Отсутствие напряжения на обесточенной плате характеризует исходное состояние. Поведение при выключении и скорость разряда определяются отдельным измерением.
